title: Підключення джерел даних і синхронізація
---
Підтримувані джерела: Google Sheets, Excel/CSV-файли, PostgreSQL, MySQL, BigQuery, а також REST API через конектор «Веб-джерело».

Як підключити:
1. «Дані» → «Додати джерело» → оберіть тип.
2. Для баз даних вкажіть хост, порт, назву бази, користувача з правами лише на читання. Додайте IP-адреси ЗвітХаб 203.0.113.10 і 203.0.113.11 до білого списку вашого сервера.
3. Натисніть «Перевірити з'єднання», потім «Зберегти».

Частота синхронізації залежить від тарифу: раз на добу («Старт»), щогодини («Команда»), кожні 5 хвилин («Бізнес»). Оновити вручну можна кнопкою «Синхронізувати зараз».

Поширені помилки:
- «Timeout»: сервер недоступний ззовні або IP не в білому списку.
- «Authentication failed»: перевірте логін/пароль; для Google Sheets перепідключіть акаунт Google.
- Дані застаріли: перевірте статус останньої синхронізації в «Дані» → «Журнал».
